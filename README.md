## 💰 Expense Tracking Chatbot

A production-ready **full-stack expense management platform** built with **Golang**, **ConnectRPC**, **Ent ORM**, **PostgreSQL**, and **Svelte**.

Instead of manually filling forms, users simply type messages like:

> *"Spent ₹500 on groceries yesterday."*

The chatbot intelligently extracts:

- Amount
- Expense Category
- Date
- Description

and automatically stores the transaction.

### Features

- JWT Authentication
- Natural Language Expense Entry
- Budget Management
- Recurring Expenses
- Monthly Analytics
- Expense Insights
- Category Management
- ConnectRPC APIs
- PostgreSQL Database
- Ent ORM
- Svelte Frontend

### Tech Stack

- Golang
- ConnectRPC
- PostgreSQL
- Ent ORM
- JWT
- Svelte
